Advanced WhatsApp Bot with Pairing Code Authentication, Multiple Commands, Games, Music Search, and Media Conversion.

## 🌟 Features

### ✨ Core Features
- ✅ **Pairing Code Authentication** - 6-digit code for quick connection
- ✅ **QR Code Connection** - Scan QR code alternative
- ✅ **Auto-Reconnect** - Automatic reconnection on disconnect
- ✅ **Multiple Commands** - 20+ built-in commands
- ✅ **Owner Protected** - Owner: `〖ᴹᴿ•ᴀʟᴇ᥊᭄𓋆 ⁰⁰³`
- ✅ **Bot Name** - Alex-MD

### 🎵 Media Features
- 🎵 Music Search & Download
- 🖼️ Image to Sticker Conversion
- 📹 View-Once Messages (`.vv` command)
- 🎬 Video Downloads
- 🔊 Audio Conversion

### 🎮 Gaming Features
- 🎲 Dice Roller
- 🪙 Coin Flipper
- ✂️ Rock Paper Scissors
- 🎯 Guess the Number
- 🎮 Tic Tac Toe
- 🎪 More games coming soon

### 📊 Utility Features
- ⏰ Time & Date
- 🧮 Calculator
- 💭 Random Quotes
- 📊 Group Info & Members
- 🔍 Search Functions

## 📋 Requirements

- **Node.js** v14.0.0 or higher
- **npm** or **yarn**
- **FFmpeg** (for media conversion)
- **Active WhatsApp Account**
